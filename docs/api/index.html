API Reference

Access the full SkillsIndex catalog via static JSON files hosted on GitHub Pages. No authentication required.

Endpoints

GET https://skillsindex-dev.github.io/skills/skills.json

Returns the complete catalog as a JSON array. Contains all 24,000+ items.

curl https://skillsindex-dev.github.io/skills/skills.json | jq '.[0]'
GET https://skillsindex-dev.github.io/skills/stats.json

Returns aggregate statistics about the catalog.

curl https://skillsindex-dev.github.io/skills/stats.json | jq

Data Schema

Each item in skills.json has the following structure:

{
  "id": "3c288ca28697",
  "name": "pandas-profiler",
  "description": "Generate profile reports from pandas DataFrames",
  "type": "skill",
  "category": "Data & Analytics",
  "source": "github",
  "url": "https://github.com/example/pandas-profiler",
  "stars": 1250,
  "author": "example",
  "tags": ["pandas", "data", "profiling"],
  "verified": true,
  "scraped_at": "2025-02-01T12:00:00Z"
}

Field Descriptions

FieldTypeDescription
idstringUnique 12-character hash identifier
namestringName of the tool
descriptionstringBrief description (may be null)
typestringOne of: skill, mcp, a2a
categorystringCategory classification
sourcestringOne of: github, smithery
urlstringRepository or registry URL
starsnumberGitHub stars (0 if not from GitHub)
authorstringAuthor or organization name
tagsarrayArray of tag strings
verifiedbooleanWhether the item is verified
scraped_atstringISO timestamp of last update

Usage Examples

JavaScript

const res = await fetch('https://skillsindex-dev.github.io/skills/skills.json');
const items = await res.json();

// Filter by type
const mcpServers = items.filter(i => i.type === 'mcp');

// Search by name
const pandas = items.filter(i =>
  i.name.toLowerCase().includes('pandas')
);

// Sort by stars
const topItems = items
  .sort((a, b) => b.stars - a.stars)
  .slice(0, 10);

Python

import requests

data = requests.get('https://skillsindex-dev.github.io/skills/skills.json').json()

# Filter by category
dev_tools = [i for i in data if i['category'] == 'Development Tools']

# Get verified items
verified = [i for i in data if i.get('verified')]

Rate Limits

The API is served via GitHub Pages CDN. There are no rate limits, but please cache responses locally when building applications.
