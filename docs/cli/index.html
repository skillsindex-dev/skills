CLI Reference

The SkillsIndex CLI (si) lets you search, install, and manage Claude tools from your terminal.

⚠️ Coming Soon

The CLI is currently in development. This documentation describes the planned functionality.

Installation

# npm
npm install -g skillsindex-cli

# yarn
yarn global add skillsindex-cli

# pnpm
pnpm add -g skillsindex-cli

Verify installation:

si --version

Commands

Search

si search <query>
Search the catalog for skills, MCP servers, or A2A agents.
# Search for pandas-related tools
si search "pandas"

# Filter by type
si search "database" --type mcp

# Filter by category
si search "security" --category Security

Install

si install <id|name>
Install a skill or MCP server.
# Install by name
si install pandas-profiler

# Install by ID
si install 3c288ca28697

# Install MCP server
si install postgres-mcp --type mcp

List

si list
List installed skills and MCP servers.
si list
si list --type skill
si list --type mcp

Doctor

si doctor
Check installation health and fix common issues.
si doctor
si doctor --fix

Kits

si kits <command>
Manage premium kits.
# List available kits
si kits list

# Install a purchased kit
si kits install data-engineer

# Update a kit
si kits update data-engineer

Auth

si auth <command>
Manage authentication for premium features.
# Login with license key
si auth login --key YOUR_LICENSE_KEY

# Check auth status
si auth status

# Logout
si auth logout

Config

si config <key> [value]
Get or set configuration options.
# View all config
si config

# Set default type filter
si config defaultType mcp

# Reset config
si config --reset

Options

FlagDescription
--version, -vShow version number
--help, -hShow help
--jsonOutput as JSON
--quiet, -qSuppress output
--verboseVerbose output

Configuration File

The CLI stores configuration in ~/.skillsindex/config.json:

{
  "licenseKey": "sk_...",
  "defaultType": null,
  "installDir": "~/.claude/skills",
  "mcpConfigPath": "~/.claude/claude_desktop_config.json"
}
