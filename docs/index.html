Quick Start

Using the API

Fetch the full catalog as JSON:

curl https://skillsindex-dev.github.io/skills/skills.json

Using the CLI

# Install CLI
npm install -g skillsindex-cli

# Search for skills
si search "pandas"

# Install a skill
si install pandas-profiler

Using Kits

# Buy and activate a kit
si auth login --key YOUR_LICENSE_KEY

# Install a kit
si kits install data-engineer
