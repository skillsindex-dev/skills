Premium Kits

Kits are curated bundles of Claude tools — skills, MCP servers, and configurations — designed for specific workflows. Each kit is hand-picked, tested, and documented.

What's in a Kit?

Each kit includes:

  • Curated Skills — 25-50 hand-picked skills that work well together
  • MCP Servers — Pre-configured servers for databases, APIs, and services
  • Configuration Files — Ready-to-use JSON configs
  • Documentation — Setup guides, tutorials, and best practices
  • Lifetime Updates — New skills added as they become available

Installation

# 1. Install the CLI
npm install -g skillsindex-cli

# 2. Login with your license key
si auth login --key YOUR_LICENSE_KEY

# 3. Install your kit
si kits install data-engineer
