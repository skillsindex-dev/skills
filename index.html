Frequently Asked Questions

Everything you need to know about the Claude ecosystem

What are Claude Skills?

Claude Skills are reusable prompts and instructions that extend Claude's capabilities for specific tasks. They can be installed in Claude Code to add new slash commands, workflows, and specialized behaviors.

Skills are defined in .md files with YAML frontmatter and can include system prompts, examples, and structured instructions. The SkillsIndex catalogs over 21,000 skills from official Anthropic sources, Smithery.ai, and community repositories.

What is MCP (Model Context Protocol)?

MCP (Model Context Protocol) is an open protocol developed by Anthropic that allows AI assistants like Claude to connect with external data sources and tools securely.

MCP Servers provide capabilities like:

  • File system access and management
  • Database connections (PostgreSQL, SQLite, etc.)
  • API integrations (GitHub, Slack, etc.)
  • Browser automation and web scraping
  • Code execution environments

SkillsIndex tracks over 2,800 MCP servers from the official repository and community sources.

What are A2A Agents?

A2A (Agent-to-Agent) is an emerging protocol for AI agents to communicate and collaborate with each other. A2A enables:

  • Task delegation between specialized agents
  • Context sharing across agent boundaries
  • Multi-agent workflows and orchestration

The catalog currently includes early A2A agent implementations as the ecosystem develops.

How often is the data updated?

The SkillsIndex catalog is updated daily at 06:00 UTC via automated GitHub Actions. The scraper collects data from 18 different sources:

  • Smithery.ai — 30K+ skills, 1.8K+ MCP servers
  • Official repositories — anthropics/skills, modelcontextprotocol/servers
  • Community collections — punkpeye/awesome-mcp-servers, VoltAgent/awesome-agent-skills
Is the data free to use?

Yes! All data is freely available under open terms. You can use it for:

  • Building your own applications and tools
  • Research and analysis
  • Integration into other catalogs or directories

Data is available in two formats:

  • JSON (18 MB) — Best for web applications
  • Parquet (3.7 MB) — 5x smaller, ideal for data analysis with pandas
How can I contribute or submit my skill/server?

There are several ways to get your skill or MCP server included:

  • Publish on Smithery.ai — Items are automatically scraped daily
  • Add to awesome-lists — Submit a PR to punkpeye/awesome-mcp-servers or similar collections
  • Create a public GitHub repo — Use the standard SKILL.md format for skills

The scraper automatically discovers and indexes new items from all tracked sources.

How do I install a Claude Skill?

To install a Claude Skill in Claude Code, use one of these methods:

  • claude skill add <skill-name> — Install from Smithery registry
  • claude skill add <github-url> — Install from GitHub repository
  • /install-skill — Use the built-in slash command

Once installed, skills add new slash commands and capabilities to your Claude Code session.

How do I add an MCP Server to Claude?

MCP Servers can be configured in two ways:

  • Claude Desktop: Edit claude_desktop_config.json in your config directory
  • Claude Code: Use claude mcp add <server> command

Each server provides specific capabilities. For example, the filesystem server enables file operations, while postgres server provides database access.

What is the difference between Skills and MCP Servers?

Skills and MCP Servers serve different purposes:

  • Skills are prompt-based instructions that define how Claude should behave for specific tasks. They're like custom commands or workflows defined in markdown.
  • MCP Servers are actual executable code that runs alongside Claude, providing real-time access to external systems, databases, and APIs.

Think of it this way: Skills customize Claude's responses, while MCP Servers extend what Claude can actually do.

What sources does SkillsIndex aggregate from?

SkillsIndex aggregates data from 18 sources across the ecosystem:

  • Registries: Smithery.ai, NPM (@anthropic packages), PyPI (mcp-* packages)
  • Official: anthropics/skills, modelcontextprotocol/servers, google/A2A
  • Awesome Lists: awesome-mcp-servers, awesome-claude-code, awesome-a2a, awesome-agent-skills
  • Community: Various GitHub repositories with Skills and MCP implementations

Each source is scraped daily at 06:00 UTC, with deduplication across sources.
