elfiee-fe-dev

by h2oslabs frontend

Elfiee 前端开发专家 skill。适用于 React/TypeScript 前端开发任务，包括：(1) React 组件开发 - UI 界面和交互逻辑；(2) Zustand 状态管理 - Actions 和 Store 设计；(3) Tauri IPC 调用 - 通过 TauriClient 与后端通信。遵循三大硬性规则：只通过 Zustand Actions 操作数据、禁止手动编辑 bindings.ts、不直接修改状态对象。触发示例："修改 UI 组件"、"添加前端功能"、"实现状态管理"。
