jlens-mcp

by bhxch ai-ml

专业级 Java 代码库分析与 Maven 依赖管理技能。当需要进行以下操作时触发：(1) 在多模块项目中使用多版本隔离技术分析 Java 类结构，(2) 深度解析 Maven 依赖树及排查版本冲突，(3) 利用游标分页在海量 Jar 包中搜索类，(4) 自动化执行 Maven 构建任务，(5) 智能识别本地源码与第三方库。本技能指导 Agent 优先使用已注册的 MCP 服务，并提供命令行模式的 Fallback 机制。
